## What was built

An independent oracle: Excel formulas written on a copy of each stock's raw Screener Data Sheet, one `ORACLE_<stock>` sheet each, with the value, the formula in words, the source cells and the tolerance for every metric. The code was then run on the same facts and price (the export's Current Price) and compared.
